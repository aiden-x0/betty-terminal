# Betty Terminal
A read-only Streamlit dashboard that charts the performance of the Betty football prediction engine against closing bookmaker odds: edge curve, calibration, league heatmap and outcome mix.
It reads two CSV files in data/ and never writes anything.
Run locally: pip install -r terminal_app/requirements.txt, then streamlit run terminal_app/app.py
Data is a snapshot copied from the private Betty project and may lag behind it.
This is a statistical research display, not betting advice.
